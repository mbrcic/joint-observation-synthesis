# Bounded strategic evidence-production bridge

The formal kernel settles **informational** coverage: `qCD` separates all four executions
when fed the principals' actual private fields. That is a theorem. That the fields *are*
supplied is not — `observe_truthful` is `rfl` and proves nothing. It exists to keep the
assumption visible.

This directory contains a bounded enumeration of whether principals who prefer approval to
blocking produce the evidence `qCD` needs. It is separate from the informational kernel
and reports the outcomes of the declared payoff table and parameter grid.

## The model

Two principals, one shot, simultaneous. Full statement: `python3 game.py`.

| | |
|---|---|
| Actions | `restricted`, `unrestricted`, `not_established` |
| Outcome | blocked **iff both** assert `restricted` |
| Payoff to `i` | `G` if not blocked, `0` if blocked, less `p·L` for a false assertion, less `W` for declining to assert |

The outcome rule is not a modelling choice made for convenience — it mirrors
`qCD.joint = a && b` in the Lean instance. **A conjunction gives each evidence holder a
unilateral veto over its own detection.** That is the precise sense in which an
informationally sufficient predicate can be strategically unavailable, and it is why the
two layers cannot be assessed separately.

Everything is enumerated. The game is 3×3 with closed-form payoffs, so each result below
is checked by evaluating every cell over a parameter grid rather than argued.

## Results

**R1 — the falsification threshold, derived.** With only assertions available, truthful
reporting is weakly dominant for the model owner exactly when `p·L ≥ G`. The threshold is
derived from the payoff table and checked by enumeration.

**R2 — the third action adds a second condition.** Withholding also defeats the
conjunction, and costs `W` rather than `p·L`. The full condition is `p·L ≥ G` **and**
`W ≥ G`. A mechanism designed against lying, silent about silence, does not survive
contact with the option set.

**R3 — negative result.** At `G=1, p=0, L=0, W=0`, truthful reporting is not an
equilibrium at `sigma11` and the model owner has a strictly profitable deviation of
`+1.00`.

**R4 — positive result: production reliability, universally.** At `G=1, p=0.6, L=2,
W=1.5` — strict inequalities, so `p·L > G` and `W > G` — truthful reporting is strictly
dominant, the equilibrium set collapses to the single outcome `(restricted, restricted)`,
and **every** admitted outcome supplies the coalition's evidence. This is the
production-reliability property: evidence must be available under every strategic outcome
admitted by the declared solution concept.

**R4b — and the property fails at the equality boundary.** At `p·L = G` and `W = G`,
suppression is merely *indifferent* rather than worse, so four non-producing equilibria
survive alongside the truthful one.

R4b is retained deliberately. It is what an earlier version of this file reported as its
positive result — `truthful_pair in equilibria`, which says truth is *an* equilibrium and
nothing more. Two independent adversarial reviews caught that it does not establish
production reliability, and they were right: at that parameter point the mechanism admits
four outcomes in which the alarm never fires. The difference between R4 and R4b is the
entire content of the word "reliably".

**R5 — pivotality.** A principal's report changes its payoff only when the other asserts
restriction. Everywhere else the choice is payoff-irrelevant.

R5 is visible in the released traces. The `pivotal` rung tells the agent it is in the only
cell where its report matters, and measured falsification jumps from 0/80 to 11/80. The
trace and game therefore expose the same non-degenerate reporting cell from two sides.

## Relation to the released traces

The released traces are generated by a separate harness and do not instantiate the payoff
parameters in this file. The game reports enumerated production conditions; the traces
report observed interface behavior. In the `--allow-withhold` arm, `W = 0` with `G > 0`
described a withholding incentive, while agents withheld in 0/80 episodes. This is a
reported divergence between the bounded model and the released traces.

## Model boundary

`game.py` implements one bounded realization of the mechanism component `M`, with a 3×3
action table, closed-form payoffs, and an explicit finite parameter grid.
